📚 Pembuat Materi Ajar

Materi terstruktur: pendahuluan, konsep dasar, pembahasan inti, contoh penerapan, poin penting, glosarium, dan pertanyaan pemantik.

📝 Pembuat Modul Ajar

Modul ajar Kurikulum Merdeka otomatis: tujuan, langkah pembelajaran dengan alokasi menit per fase, asesmen, refleksi, LKPD, dan rubrik.

📋 Bank Soal

Paket soal lengkap: pilihan ganda, HOTS (C4–C5), esai, kunci jawaban, dan pembahasan — siap diedit dan dicetak.

📊 Pembuat Presentasi

Outline slide lengkap: pembuka, tujuan, isi bertahap, pertanyaan diskusi, dan penutup — lengkap dengan saran visual dan catatan guru. Setelah jadi, klik 🖼️ Mode Slide untuk pratinjau kartu slide.

🎯 Kuis Interaktif

Buat kuis siap main: timer per soal, skor otomatis, umpan balik langsung, dan layar hasil beserta pembahasan. Cocok dimainkan langsung di kelas atau oleh siswa di rumah.

🎮 Cara main: setelah kuis dibuat, klik tombol ▶️ Mulai Kuis Interaktif pada panel dokumen. Kuis yang disimpan di 📁 Dokumen Saya juga bisa dimainkan ulang kapan saja.

📑 Pembuat LKPD

Lembar Kerja Peserta Didik lengkap: identitas, tujuan, petunjuk, kegiatan bertahap dengan tabel data, analisis, kesimpulan, refleksi, dan rubrik penilaian singkat.

📈 Instrumen Penilaian

Enam instrumen asesmen siap pakai: rubrik penilaian (presentasi, proyek, diskusi, kinerja), lembar observasi & jurnal sikap, hingga kisi-kisi soal sumatif dengan bobot skor.

💡 Ide Mengajar

Inspirasi konkret sesuai topik Anda: ide pembuka kelas, aktivitas inti, media pembelajaran, proyek kreatif, hingga strategi diferensiasi — lengkap dengan langkah singkat dan perkiraan waktu.

🤖 Asisten AI

Chatbot pendamping pembelajaran: ide aktivitas, strategi kelas, tips soal HOTS, dan panduan fitur GURU SMART.

📁 Dokumen Saya

Hasil pekerjaan tersimpan di perangkat ini (localStorage) — dapat dibuka kembali, disalin, dicetak, atau diunduh.

🕒 Riwayat AI

Setiap hasil generasi AI otomatis tercatat di sini (30 terakhir). Lupa menekan 💾 Simpan? Hasil tetap bisa dibuka ulang, disalin, dicetak, diunduh, atau disimpan ke Dokumen Saya.

⚙️ Pengaturan

Akun guru, AI Gemini, sinkronisasi cloud Supabase, dan cadangan data — semuanya dalam satu tempat.

👤 Akun Guru

🔑 AI Gemini

Tanpa API key, aplikasi berjalan dalam Mode Demo (templat pedagogis siap pakai). Dengan key, semua generator memakai AI sesuai topik Anda.

🔒 Key disimpan hanya di browser Anda (localStorage). Sesuai rencana arsitektur, pada produksi key sebaiknya disimpan di backend (Supabase Edge Functions) — bukan ditanam dalam HTML. Jika suatu model sudah tidak tersedia, aplikasi otomatis beralih ke model pengganti yang disarankan Google dan menyimpannya.

☁️ Sinkronisasi Supabase (opsional)

Data Anda selalu tersimpan otomatis di perangkat. Hubungkan project Supabase untuk menyalin data ke cloud — berguna untuk berpindah perangkat atau sebagai cadangan kedua. Proyek & key Supabase tidak disertakan? Semua fitur tetap jalan normal.

—

Penyiapan database (sekali saja) — buka SQL Editor di dashboard Supabase Anda, lalu jalankan:

create table if not exists public.guru_data ( user_key text not null, kind text not null, -- profile | docs | chat | quizScores | history payload jsonb not null, updated_at timestamptz not null default now(), primary key (user_key, kind) ); alter table public.guru_data enable row level security; -- Untuk uji coba cepat (tanpa login Supabase): create policy "akses anon (uji coba)" on public.guru_data for all using (true) with check (true);
⚠️ Policy di atas membuka akses anon untuk uji coba. Untuk produksi: gunakan Supabase Auth + kebijakan RLS per pengguna, dan simpan Gemini API key di Edge Functions.

💾 Cadangan & Pulihkan

Unduh seluruh data akun aktif (profil, dokumen, chat, skor kuis, riwayat) sebagai satu file JSON, lalu pulihkan di perangkat mana pun — tanpa internet. API key sengaja tidak disertakan demi keamanan.
